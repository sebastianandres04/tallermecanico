# ⚙️ GENERAL MECHANIC — Sitio Web de Taller Mecánico

## 🧾 Descripción del Proyecto

Sitio web corporativo desarrollado para **GENERAL MECHANIC**, un taller mecánico profesional.  
El proyecto presenta una interfaz moderna, totalmente **responsive** y funcional, que permite a los clientes conocer los servicios, visualizar trabajos realizados y establecer contacto directo con el taller.

---

## 🚗 Características Principales

- **Diseño Responsive:** Adaptado a dispositivos móviles, tablets y equipos de escritorio.  
- **Navegación Intuitiva:** Menú tipo *hamburguesa* para móviles con animaciones fluidas.  
- **Secciones Completas:**
  - Hero Section con llamada a la acción.  
  - Servicios (Mecánica General, Cambio de Aceite, Reparaciones, Diagnóstico Electrónico).  
  - Información sobre la empresa.  
  - Galería de trabajos realizados.  
  - Formulario de contacto con validación.  
- **Interactividad:** Efectos *hover*, animaciones al hacer *scroll* y transiciones suaves.  
- **Validación de Formularios:** Incluye verificación de correo electrónico y número telefónico chileno (+56 9).  
- **UI/UX Moderna:** Diseño limpio, paleta de colores profesional y uso de iconografía **Font Awesome**.  

---

## 🧠 Tecnologías Utilizadas

- **HTML5:** Estructura semántica del sitio.  
- **CSS3:** Variables CSS, Flexbox, Grid, animaciones y diseño adaptable.  
- **JavaScript (Vanilla):** Interactividad, validación de formularios y animaciones.  
- **Font Awesome:** Iconografía moderna y coherente.  

---

## ⚙️ Funcionalidades Técnicas

- Navegación con desplazamiento suave (*smooth scroll*).  
- Validación de formularios en el frontend.  
- Animaciones dinámicas al desplazarse por la página.  
- Menú móvil animado y adaptable.  
- Efectos *hover* en tarjetas de servicios.  
- Almacenamiento local de mensajes enviados desde el formulario.  

---

## 🌐 Resultado

El resultado es un **sitio web profesional y eficiente** que refuerza la presencia digital de **GENERAL MECHANIC**, facilitando el acceso a información sobre servicios, promoviendo la confianza del cliente y simplificando el proceso de contacto.
